# Nexus — SaaS Landing Page Template

A fully self-contained, production-ready landing page for a SaaS product. Single `index.html` file with zero dependencies — deploy anywhere in seconds.

---

## Live Demo

Open `index.html` in any browser, or deploy to GitHub Pages with one push.

---

## What's Inside

The page is structured as a complete conversion funnel:

| Section | Description |
|---|---|
| **Navigation** | Sticky top nav with logo, 3 links, login modal, mobile burger menu |
| **Hero** | Headline, sub-headline, dual CTA buttons, social proof counter |
| **Dashboard Preview** | Animated live-data mini kanban board (JS-driven counters) |
| **Logos Strip** | "Trusted by teams at…" logo row |
| **Device Showcase** | CSS-drawn desktop / tablet / mobile device frames |
| **Features (Roadmap)** | 3-phase product roadmap: Live → In Progress → Coming Soon |
| **How It Works** | 3 equal step cards with centered numbers and interactive visuals |
| **Testimonials** | Masonry column layout, 5-star reviews |
| **Pricing** | 4-tier grid (Starter / Standard / Pro / Enterprise) with monthly ↔ yearly toggle |
| **Book a Demo** | Google Forms-style validated form |
| **Newsletter** | Email opt-in with inline validation |
| **FAQ** | Accessible accordion with smooth open/close animation |
| **CTA Banner** | Full-width conversion banner |
| **Footer** | 4-column grid, social links (X / GitHub / LinkedIn), legal links |

## How to Use as a Template

### 1. Clone or Download

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

Or simply download `index.html` — it is the entire project.

### 2. Find and Replace Your Brand

Open `index.html` in any text editor and replace the following:

| Placeholder | What to change |
|---|---|
| `Nexus` | Your product name |
| `#6D28D9` / `var(--violet)` | Your brand primary colour |
| `nexus.app` | Your domain |
